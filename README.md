# Entometría

Software de visión por computadora para medir insectos con la cámara del celular, de la computadora
o del microscopio: cuerpo, cabeza, tórax y abdomen, patas y antenas, alas con sus nervaduras y celdas,
conteos en trampas y medidas a mano, con exportación a Excel, TPS y Procrustes.

**Abrir la app:** https://jmezosolis.github.io/entometria/

Se instala desde el navegador y funciona sin internet. Este repositorio contiene solo la versión
publicada de la app; el código fuente no es público. Todos los derechos reservados.
